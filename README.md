# Hotel Booking System

A full-featured Hotel Booking web application built with Django. Users can browse hotels and rooms, create an account, log in using Google OAuth, book rooms, and make online payments.

## Live Demo

🌐 Live Website: https://hotel-booking-fasq.onrender.com/

---

## Features

- User Registration and Login
- Google OAuth Authentication
- Browse Hotels
- View Hotel Details
- Browse Available Rooms
- Room Booking System
- Online Payment Integration
- Booking Management
- Django Admin Panel
- Cloudinary Media Storage
- PostgreSQL Production Database
- Responsive User Interface
